# Catalog server (SQLite)

Локальный каталог сайтов и ссылок для расширения **Video Data Extractor**.

## Запуск

```bash
cd server
npm install
npm start
```

Откройте UI: [http://127.0.0.1:3921](http://127.0.0.1:3921)

База: `server/data/catalog.db`

### Команды

| Команда | Что делает |
|---------|------------|
| `npm start` | Запустить сервер |
| `npm run stop` | Остановить процесс на порту 3921 |
| `npm run restart` | Остановить и сразу запустить снова |
| `npm run dev` | Запуск с автоперезагрузкой при правках кода |

## Как работает

1. В UI создаёте сайт, добавляете ссылки (одну или списком).
2. Включаете расписание (интервал в часах) или жмёте «Запустить обход сейчас».
3. Расширение раз в минуту опрашивает сервер (`/api/jobs/claim`) и запускает массовое обновление (как bulk → `updatelink`).
4. Ошибки title / news_not_found / captcha попадают в **Не обработанные** (`needs_admin`).
5. Кнопка «Парсить → админка» ставит задачу; расширение вызывает полный парсинг и открывает DLE-админку.

## Требования

- Node.js 18+
- Chrome с загруженным расширением
- Сервер должен быть запущен во время обхода
- Капча на сайтах-источниках по-прежнему решается вручную во вкладке worker

## Порт

По умолчанию `127.0.0.1:3921`. Переменные:

- `CATALOG_HOST`
- `CATALOG_PORT`
