Настройки обхода

Эти параметры действуют для всех ссылок выбранного сайта. После изменений нажмите «Сохранить настройки».

Сервер сам ставит сайт в очередь, когда подходит время следующего обхода. Нужны открытый Chrome и запущенный сервер.

Например 6 — примерно каждые 6 часов; 24 — раз в сутки после прошлого завершения.

Включить, если нужно обновлять ссылки на серии/плееры. Выключить — только проверить/обновить карточку по названию и году.

Число в адресе страницы, например /1546-название.html. Новые ссылки вставляют в очередь по этому правилу, а не по дате добавления.

Добавить ссылки для парсинга

Сюда вставляйте адреса страниц сериалов или фильмов на сайте-источнике. При обходе расширение откроет каждую и отправит данные в russerialov.

Список ссылок

Статус последнего обхода по каждой странице. Порядок обхода настраивается на вкладке «Настройки». На странице показывается по 50 ссылок.

Необработанные ссылки

Сюда попадают страницы, которые массовый обход не смог обновить. Для каждой ссылки можно: скопировать, сразу запустить парсинг в админку, отметить готовой или удалить.

На странице показывается по 50 ссылок. Сортировка по году и шарингу работает по всему списку.
